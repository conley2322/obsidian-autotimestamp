

## What Changes
- 创建一个新的 Obsidian 插件项目，使用 Vue 3 (setup 语法糖) 框架
- 实现回车键监听，自动在行末插入可自定义格式的时间戳
- 提供设置页面，允许用户自定义时间格式
- 实现渲染开关功能，控制时间戳在阅读模式下的显示/隐藏

## Impact
- 创建新项目，无现有代码影响
- 需要安装 Vue 3 及相关依赖

## ADDED Requirements

### Requirement: 时间戳自动插入
系统应当在用户按下回车键时，自动在当前行末尾插入时间戳。

#### Scenario: 正常插入时间戳
- **WHEN** 用户在编辑模式下按下回车键
- **THEN** 系统在当前行末尾插入格式化的时间戳（默认格式：YYYY-MM-DD HH:mm:ss）

#### Scenario: 自定义时间格式
- **WHEN** 用户在设置中修改时间格式
- **THEN** 后续插入的时间戳使用新的格式

### Requirement: 时间格式设置
系统应当允许用户自定义时间戳的显示格式。

#### Scenario: 修改时间格式
- **WHEN** 用户在插件设置页面输入自定义的时间格式字符串
- **THEN** 系统保存该格式并用于后续的时间戳生成

### Requirement: 渲染开关控制
系统应当提供一个开关来控制时间戳在阅读模式下的显示。

#### Scenario: 开启渲染
- **WHEN** 用户开启"显示时间戳"选项
- **THEN** 在阅读模式下显示所有时间戳

#### Scenario: 关闭渲染
- **WHEN** 用户关闭"显示时间戳"选项
- **THEN** 在阅读模式下隐藏时间戳，但编辑模式下仍然可见

### Requirement: Vue 3 技术栈
系统应当使用 Vue 3 的 setup 语法糖格式进行开发。

#### Scenario: 组件开发
- **WHEN** 开发设置页面组件
- **THEN** 使用 `<script setup lang="ts">` 语法
# Obsidian 回车时间戳插件 Spec

## Why
用户在 Obsidian 中编辑 Markdown 文档时，希望在每次按下回车键后自动在行末添加时间戳，以便记录每段内容的创建/编辑时间。同时需要能够控制是否在渲染模式下显示这些时间戳。
