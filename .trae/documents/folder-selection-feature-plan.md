# 文件夹选择功能实现计划

## 需求概述

为 Obsidian Enter Timestamp 插件添加文件夹选择功能：

* 获取仓库中所有文件夹（包括子文件夹）

* 在设置界面进行勾选选择

* 只有勾选的文件夹中的文件才会触发插件功能

* 可以与现有的文件名匹配功能一起使用（AND 逻辑）

## 实现步骤

### 1. 扩展设置接口 (main.ts)

在 `EnterTimestampSettings` 接口中添加：

```typescript
enabledFolders: string[];  // 存储启用的文件夹路径
```

更新 `DEFAULT_SETTINGS`：

```typescript
enabledFolders: []  // 默认空数组表示所有文件夹都启用
```

### 2. 添加文件夹过滤逻辑 (main.ts)

修改 `isFileEnabled` 方法：

* 检查当前文件所在文件夹是否在启用列表中

* 如果 `enabledFolders` 为空，则所有文件夹都启用（保持向后兼容）

* 文件夹检查逻辑：检查文件路径是否以任一启用的文件夹路径开头

### 3. 获取文件夹列表功能 (main.ts)

添加方法获取仓库所有文件夹：

```typescript
getAllFolders(): string[] {
  // 遍历 app.vault.getAllLoadedFiles()
  // 过滤出文件夹类型
  // 返回文件夹路径数组
}
```

### 4. 更新设置界面 (SettingTab.vue)

添加文件夹选择 UI 组件：

* 显示所有文件夹列表（树形或平铺展示）

* 每个文件夹前有复选框

* 支持全选/取消全选

* 显示文件夹层级关系

### 5. 传递文件夹数据到 Vue 组件

修改 `EnterTimestampSettingTab` 的 `display` 方法：

* 将 `getAllFolders()` 方法或文件夹列表传递给 Vue 组件

* 组件需要能够调用刷新文件夹列表

### 6. 文件过滤逻辑整合

最终过滤逻辑：

```
文件启用 = (文件夹匹配 || enabledFolders为空) && (文件名匹配 || fileNamePattern为空)
```

## 注意事项

1. **向后兼容**：`enabledFolders` 为空时，所有文件夹都启用，保持现有行为
2. **性能考虑**：文件夹列表在设置界面打开时获取，不缓存
3. **路径格式**：使用 Obsidian 内部路径格式（正斜杠分隔）
4. **子文件夹匹配**：勾选父文件夹时，子文件夹下的文件也会被匹配
