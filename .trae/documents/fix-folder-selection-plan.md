# 修复文件夹选择和文件名匹配功能

## 问题

当前实现无法正常工作，需要修改为：

1. 文件夹选择改为下拉框形式，选择后添加到列表中（标签形式显示）
2. 文件名匹配和文件夹选择可以同时生效

## 实现步骤

### 1. 修改 SettingTab.vue

**文件夹选择改为下拉框 + 标签形式：**

* 下拉框显示所有可选文件夹

* 选择后添加到已选列表

* 已选文件夹以标签形式显示，可点击删除

* 添加"清空所有"按钮

**文件名匹配：**

* 保持输入框形式

* 与文件夹选择独立，同时生效

### 2. 修改 main.ts

**修复文件检查逻辑：**

* 确保文件夹检查正确匹配路径

* 确保文件名匹配正确工作

* 两个条件同时满足才启用插件

### 3. UI 设计

```
启用的文件夹：
[下拉框选择文件夹 ▼]

已选择的文件夹：
[文件夹1 ×] [文件夹2 ×] [文件夹3 ×]
[清空所有]

文件名匹配模式：
[输入框]
```
